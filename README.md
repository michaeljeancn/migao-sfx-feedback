# 音效工作台 · 错误反馈

这里是「米糕声音坊 · 音效工作台」的用户反馈入口。**本仓库只收 issue，不放源代码**（代码在私有库里）。

## 怎么提交

打开软件 → 菜单 **帮助 → 报告问题…**（或按 `F2`）→ 点 **用 GitHub 提交**。
软件已经按当前出错现场把标题和正文填好，你只要在打开的页面里点 **Submit new issue**。

也可以在软件里点 **用邮件发送**，发到 <michaeljeancn@outlook.com>。

## 会自动带上什么

- 捕获到的异常信息与调用栈（页面路径已脱敏成 `<应用>/xxx.html:行:列`）
- 应用版本、页面版本指纹、Windows 与 WebView2 版本
- 深浅色、缩放比例、当前面板、项目 id 前 8 位、原稿份数
- 最近 10 步操作

**不会带**：书名、原文正文、文件与目录路径。

## 提交前

- 补一句「当时在做什么」，比如「点确认修改完毕之后白屏」——这比堆栈有用得多。
- 不要贴整章正文；需要举例就贴几行。
- 如果是「点了没反应」，也请照常提交：桥接命令失败会自动记进错误列表。
